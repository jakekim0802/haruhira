# 하루히라 (haruhira)

히라가나를 보고 한국어 발음 네 개 중 정답을 선택하는 모바일 우선 정적 웹앱입니다.

**웹앱 주소:** https://jakekim0802.github.io/haruhira/ (Pages 배포 완료 후 접속 가능)

## 학습 기능

- 기본 46자 / 탁음·반탁음 25자 / 요음 33자 / 전체 104자
- 한 라운드 10문제, 라운드 내 중복 없는 문제
- 서로 다른 한국어 발음 네 개와 하나의 정답
- 즉시 정오답 표시, 진행률, 정답 수, 연속 정답
- 라운드 결과와 다시 연습
- 모바일 터치 화면 및 키보드 접근성 지원
- 외부 라이브러리, 빌드, 로그인, 서버 및 API 키 불필요

한글 읽기는 암기를 돕는 근사 표기입니다. 실제 일본어 발음과 차이가 있으며, は·へ는 조사로 쓰일 때 읽기가 달라집니다.

## GitHub Pages 설정

이 저장소의 `Settings → Pages`에서 다음을 선택합니다.

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- **Save**

`index.html`과 `.nojekyll`이 저장소 최상위에 있습니다. 최초 설정 이후 main 브랜치의 변경 사항이 배포됩니다. 배포 진행과 오류는 Actions에서 확인할 수 있습니다.

## 점검

배포 전 Chromium에서 Playwright로 HTML을 렌더링하여 확인했습니다. 실제 iPhone/Safari 기기 테스트를 의미하지는 않습니다.

- 학습 데이터 46 / 25 / 33 / 104개 및 전체 글자 중복 없음
- 보기 생성 20,800회: 서로 다른 보기 네 개, 정답 한 개
- 네 모드에서 10문제 진행·정오답 점수·중복 클릭 방지·결과·재시작
- 학습 도중 모드 전환 시 상태 초기화
- 320 / 375 / 390 / 430 / 1280px 화면 너비에서 가로 넘침 없음
- 실행 중 JavaScript 오류 없음

## 로컬 실행

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000/ 을 엽니다. 휴대폰에서는 HTML 파일 미리보기 대신 배포된 HTTPS 웹앱 주소로 접속하세요.
